# Ghaith Sans (local)

Place licensed Ghaith Sans web files here:

- `GhaithSans-Regular.woff2` (400)
- `GhaithSans-Medium.woff2` (500)
- `GhaithSans-SemiBold.woff2` (600)
- `GhaithSans-Bold.woff2` (700)

Get a proper webfont license from [GHEEN / MyFonts](https://www.myfonts.com/collections/ghaith-sans-font-ali-almeethali/).

Until files are present, Arabic falls back to **Thmanyah Sans** / **Thmanyah Serif Display**.
